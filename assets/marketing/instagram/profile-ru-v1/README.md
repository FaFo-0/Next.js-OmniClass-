## One open caveat — the name field carries no search term

Instagram indexes the *name* field for search. `Английский, который не забывается` is a slogan: it reads well on the profile but nobody types it into search, so the field returns no discovery traffic. Everything people actually search (`английский для взрослых`, `английский онлайн`) lives in the bio, which is not indexed the same way.

A one-line change that keeps the settled slogan and adds the search term:

```
Omnica English | Английский для взрослых. Не забывается. 🇬🇧
```
(59/64. Writing it inline as a clause — `Английский для взрослых, который не забывается` — overflows at 66/64.)

Not applied; FaFo's call.
